# 🌤️ Weather App

A modern and responsive weather application that provides real-time weather information for any city around the world.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature updates
- 💨 Wind speed information
- 💧 Humidity details
- ☁️ Weather condition display
- 🎨 Beautiful user interface
- 📱 Fully responsive design
- ⚡ Fast and lightweight

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeather API
